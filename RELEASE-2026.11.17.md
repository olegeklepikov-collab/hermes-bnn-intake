# Выпуск 2026.11.17: контекст и точная доставка JSON

Memory 2.0.0-dev.55 / Intake 0.14.15. Полный нейтральный архив опубликован частями в Releases полного репозитория; CURRENT-RELEASE.json содержит точные ссылки, размер, SHA-256 и исходный коммит. Старые выпуски сохраняются.

## Исправления

- Подготовка длинного контекста выполняется до следующего запроса модели; сжатие штатной истории не теряет привязку рабочей задачи и ранее сохранённые результаты.
- Защитная обработка разделителей сохраняет точные декодированные ключи и значения JSON. Неизменившийся назначенный файл больше не объявляется изменённым из-за штатной обработки сообщения.
- Действительная смена SHA файла и повреждение доставленного фрагмента различаются. Прежняя известная проекция принимается только при точном совпадении и явном указании происхождения; произвольное искажение не принимается.
- Требования к полноте чтения и точности текста разделены. Файл и запрос хешируются один раз за проверку, без кэша между запросами. Совет уменьшить задачу не применяется к ошибкам целостности.

## Фактические проверки

444 нативных проверки Intake, 42 проверки защитной обёртки ядра и 104 проверки сборки прошли. Целевой набор из 38 случаев входит в 444 и не суммируется повторно. Реальный основной агент и дочерний читатель прочитали два файла четырьмя страницами, сохранив точный JSON; основной агент полностью прочитал типизированный результат и проверил его хеш.

Подтверждены одна новая нативная установка TEST и одно обновление существующего TEST с прежней парой dev.54 / 0.14.14. При обновлении сохранены SQL-строки, история и настройки. Та же прежняя синтетическая сессия продолжилась с настоящим ответом модели. Эти два вида установки различаются в подписанном QUALIFICATION-SUMMARY.json.

Архив содержит 241 861 проверенный объект; каждый прочитан и сверен с составом выпуска. Подписи и все SHA частей проверяются до установки. Код поставщиков не подменён. Ключи, личные данные и история прежнего владельца в нейтральный выпуск не входят.

## Установка и границы

Для новой установки используйте цельный выпуск 2026.11.17 и его INSTALL.md, затем Hermes-BNN-Full/docs/INSTALL_MACOS.md. Историческая цепочка исправлений не нужна. Отдельный пакет Intake требует точной пары с Memory dev.55 и не заменяет полную платформу.

Для существующего профиля требуется предусмотренная процедура обновления с резервом, проверкой исходной пары и сохранением данных. Чистая установка не является миграцией. Архив владельца от 4 ноября остаётся отдельным историческим зашифрованным снимком с Memory dev.53 / Intake 0.14.13; его состав и подписи не переобозначаются как новая программа.

Проверка всех внешних сервисов заново, другой физический Mac и полная распаковка на пустой диск этим выпуском не заявлены. Автоматического изменения действующего BNN публикация не выполняет.
