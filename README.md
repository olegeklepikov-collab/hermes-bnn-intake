# Hermes BNN Intake 0.14.15

Текущая исходная пара: Memory 2.0.0-dev.55 + Intake 0.14.15. Закреплены точные байты Memory и управляющего слоя Hermes. Алгоритмы Intake сохранены; подтверждена точная совместимость с редакцией памяти, поддерживающей доставку файлов до настройки необязательных эмбеддингов и контроль жизнеспособности длинных профилей.

Полная установка выполняется цельным архивом по [инструкции](https://github.com/olegeklepikov-collab/hermes-bnn-full/blob/main/product/docs/INSTALL_MACOS.md). Исторические исправления вручную не накладываются. Отдельное сопровождение: [INTEGRATION.md](INTEGRATION.md). Архитектура и схемы находятся в docs/ARCHITECTURE.md, docs/REQUIREMENTS.json и docs/TOOL_CATALOG.json.

Семь инструментов, открытый каталог методов, шесть профилей, атомарная декомпозиция, документы, опрос и его ограничения, восполнение лакун, делегирование и системная приёмка используют один Host/Store. Режимы /intake off, /intake auto и /intake on; новые беседы начинают с off. Внешнее человеческое ревью рекомендуется адресно и не блокирует выпуск.

Проверка пакета: tools/verify_package.py; нативные испытания: tools/run_native_tests.py. Подробности и область действительности свидетельств: [docs/VERIFICATION.md](docs/VERIFICATION.md). packages/manifest.json и PACKAGE-MANIFEST.json относятся к текущим байтам; provenance и исторические манифесты сохраняют происхождение прежних поставок.

Ключи, личность, пользовательские документы и история в поставку не входят.

Редакция 0.14.15: быстрое сохранение входа в pre_llm_call; обязательная подготовка выполняется перед запросом, без гонки с 30-секундным пропуском наблюдающего обработчика. Существующий сеанс и рабочая привязка сохраняются; отказ подготовки не разрешает вызов модели.
