# Исправление контекста BNN: Memory dev.45 и Intake 0.14.4

Дата: 1 ноября 2026 года. Это обязательное программное дополнение к полной основе `full-20261031-intake-0.14.3`. Старые архивы остаются историческими снимками. Новый текущий комплект состоит из **полной основы плюс этого исправления**. Один этот ZIP не содержит все многогигабайтные среды.

## Что исправлено и проверено

После отзыва записи памяти тот же пользовательский ход мог потерять допуск контекста. Теперь готовый контекст помечается требующим обновления данных; следующая модель получает новый подписанный пакет без отозванной записи. Смена полномочий, источниковых разрешений, профиля, роли, входа и отказ подготовки сохраняют жёсткую блокировку. Контроллеры не отключены.

Проверено: 14 новых и 101 существующий сценарий; отдельная версия выпуска повторила 14 проверок. На рабочем BNN через настоящий Telegram выполнены создание, чтение и отзыв синтетической записи, продолжение того же хода, создание MD, отправка файла и серверная сверка SHA-256. Эти данные не являются новым испытанием всех исследовательских функций платформы. Доступы, личность, история и ключи в дополнение не входят.

## Новая установка на macOS Apple Silicon

1. По `download.sh` данного репозитория скачайте полную основу и `Hermes-BNN-context-refresh-20261101.zip`. Все части основы и их хеши остаются в исходном полном выпуске: https://github.com/olegeklepikov-collab/hermes-bnn-full/releases/tag/full-20261031-intake-0.14.3 . Собственные ключи для скачивания публичного комплекта не нужны.
2. Распакуйте собранный tar.gz полной основы в новую папку. Распакуйте ZIP исправления отдельно. Обозначьте полную папку комплекта как BUNDLE, папку исправления как UPDATE. Не выполняйте старый `install.sh` до следующего шага.
3. Примените дополнение к ещё не инициализированной основе. Системный Python или pip не требуются: используется Python из полного комплекта.

```sh
BUNDLE="/path/to/Hermes-BNN-Full"
UPDATE="/path/to/Hermes-BNN-context-refresh-20261101"
"$BUNDLE/Hermes/runtime/python/cpython-3.14.6-macos-aarch64-none/bin/python3.14" -s -S   "$UPDATE/apply_update.py" prepare-kit "$BUNDLE"
bash "$BUNDLE/install.sh"
```

`prepare-kit` принимает только точную исходную основу, проверяет каждый заменяемый объект и весь payload. Неизменённые файлы сохраняют исходные ожидаемые хеши; неизвестные байты не переобъявляются проверенными. Затем штатный `install.sh` проверяет весь обновлённый комплект и устанавливает согласованную пару dev.45/0.14.4. Старые файлы программ сохранены, но bootstrap выбирает новые.

4. Выполните актуальную инструкцию установки и настройки внешних инструментов в `docs/INSTALL_MACOS.md` и `docs/SERVICES.md`. Установите собственный вход в модель, эмбеддинги и отдельного Telegram-бота. Старая документация о проверках основы является историческим свидетельством, а не новой проверкой ваших аккаунтов.

## Уже установленный BNN

Для точного известного программного основания dev.43/dev.44 предусмотрен режим `install`. Перед запуском штатно остановите свой BNN и его собственные активные исполнители. Не применяйте поверх работающего профиля.

```sh
BNN="/path/to/your/Hermes"
"$BNN/hermes-agent/venv/bin/python" -B   "$UPDATE/apply_update.py" install "$BNN" --offline-attested
```

Проверяются исходники управляющего слоя, закреплённое ядро и совместимая схема. Неизвестное основание отклоняется до переключения. Создаётся закрытый установочный резерв с SQLite-снимком; новые программы размещаются отдельно. Установщик использует штатные блокировки и операции Intake, согласует точные местные runtime-хеши и подписывает новую конфигурацию. Сессионные режимы Intake не включаются автоматически. Секреты, личность и история не переносятся и не сбрасываются. После успеха запустите BNN его прежним штатным способом и проверьте контроллеры.

Для старых резервов dev.30 сначала выполните предусмотренную цепочку программных обновлений до квалифицированного основания. Если проверка отклоняет его, не редактируйте хеши вручную: используйте текущую полную программу для новой установки и отдельный проверенный процесс переноса данных. Сохранённый закрытый личный архив не заменяется обезличенным комплектом и не объявляется новым снимком.

## Откат

Остановите BNN; по установочному резерву верните прежние настройки и выбор программ штатной операцией configuration-only rollback Intake. Новые каталоги можно оставить неактивными. Не перематывайте канонические данные, неизвестные расходы и историю эффектов. Для прежнего кода требуется новая нативная подготовка следующего шага; вручную выставлять `ready` или возвращать старые полномочия нельзя.

## Границы результата

Устраняется конкретный дефект пересборки после отзыва записи. Это не включает Intake для всех новых задач, не меняет режим смыслового поиска и не исправляет отдельные ограничения каталога навыков. Архивы старых выпусков не переписываются. Подпись исходных поставщиков этим местным исправлением не заявляется; SHA-256 подтверждает целостность опубликованного дополнения, а не независимое происхождение подписи.
